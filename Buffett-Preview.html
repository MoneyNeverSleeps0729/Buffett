HOW VALUE IS ESTIMATED

숫자마다 근거가 있어야 합니다.

Owner Earnings를 기준으로 미래 주주 현금흐름을 할인해 적정 시가총액의 범위를 구합니다.

1. 같은 회사 · 같은 기간 · 같은 단위

연간 세후 순이익, 감가상각, 적절한 비현금 비용, 유지 투자, 정상 운전자본 필요액을 원문에서 확인합니다. 누락된 값을 0으로 채우거나 성장 투자를 유지 투자로 바꾸지 않습니다. 반복적인 주식보상은 무조건 더하지 않습니다.

2. 계산보다 먼저, 읽은 범위 확인

지원 파일의 모든 텍스트 구간을 순서대로 분석합니다. 지원하지 않는 형식·이미지·스캔·수식 결과 누락이 있으면 팝업으로 보완을 요청합니다. 추출한 인용과 숫자를 원문과 대조하지만 AI 판독 오류 가능성은 남아 있어 최종 확인을 요청합니다. 이는 문서 분석이며 모델 재학습이 아닙니다.

3. 추정을 버핏의 말로 포장하지 않기

성장률, 할인율, 영구성장률, 안전마진 각각의 근거를 사용자가 확인합니다. 보수적 가정과 미래 현금흐름의 현재가치라는 원칙은 원문과 연결하지만 특정 비율을 버핏의 권장 수치라고 주장하지 않습니다. 모델 초기값은 검토용입니다.

적정 시가총액 = Σ OEₜ / (1 + r)ᵗ + 잔존가치 / (1 + r)ⁿ

OEₜ = 기준 Owner Earnings × (1 + g)ᵗ
잔존가치 = OEₙ × (1 + 영구성장률) / (할인율 − 영구성장률)

4. 가격과 비교하기

현재 보통주 발행주식수와 완료된 거래일의 비조정 종가를 곱해 비교 시가총액을 구합니다. 종목과 자료의 회사가 같은지 확인합니다. 통화가 다르거나 오래된 자료이면 매매 의견을 보류합니다. 복수 주식 종류·금융업·비영업자산 조정이 필요한 회사는 이 일반 모형을 그대로 적용하기 어렵습니다.

5. 결론의 조건

보수적 시나리오에도 지정한 안전마진이 있으면 ‘매수 검토’, 기준 가치 이하이나 보수적 안전마진이 부족하면 ‘관망’, 기준 가치보다 비싸면 ‘신규 매수 보류’로 표시합니다. 개인의 보유 상황을 알 수 없으므로 자동 매도 지시는 하지 않습니다.
